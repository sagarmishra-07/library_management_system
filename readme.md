# LIBRARY MANAGEMENT SYSTEM

## Project Overview

The Library Management System is a simple console-based application developed using Python.

The project is designed for basic library operations such as viewing books, searching for books, searching by category, issuing books, returning books, viewing library members, and checking library statistics.

The project does not use a graphical user interface or database. It uses basic Python concepts and a text file to store transaction information.

---

## Objectives

The main objectives of this project are:

1. To understand basic Python programming.
2. To practice different Python data structures.
3. To understand the use of functions.
4. To understand Python modules.
5. To practice conditional statements and loops.
6. To implement basic file handling.
7. To create a simple real-world application using Python.

---

## Features

The Library Management System provides the following features:

- View available books
- Search for a book by title
- Search books by category
- Issue a book to a library member
- Return an issued book
- View all library members
- View library statistics
- Keep track of issued books
- Store issue and return transactions in a text file
